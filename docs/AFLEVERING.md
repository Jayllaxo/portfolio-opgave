# Krav og aflevering

Grundlag: Temabeskrivelse Showreel, 2. semester, Zealand.

## Implementeret i koden
- Forside med tydeligt showreelområde (video mangler stadig).
- Om mig med navn og introduktion, der kan tilpasses.
- Projektoversigt med billeder og tekst (markeret eksempelindhold).
- Kontaktmail: skaarnet@gmail.com.
- Semantiske HTML5-elementer, dansk sprog og beskrivende sidetitel.
- Mobile first, Flexbox og Grid, ingen frameworks.
- JavaScript-interaktion: projektfiltre og mobilmenu med Escape-lukning.
- Tastaturfokus, springlink, alt-tekster og statusbesked til skærmlæsere.
- Systemfonts, små lokale SVG-filer og lazy loading af projektbilleder.
- .gitignore, README og commits af de faktiske implementeringstrin.

## Du mangler før aflevering
- Lav og indsæt din egen showreel på ca. 60–90 sekunder, optimeret til web.
- Erstat projektkort med dine egne billeder/videoer og beskrivelser af rolle,
  proces og resultat. Eksempelillustrationerne er ikke dine studieprojekter.
- Tilpas om mig-teksten; tilføj eventuelt eget portræt og relevante links.
- Kontrollér at video kan afspilles på mobil og computer; tilføj undertekster
  ved tale, og sørg for rettigheder til musik og billeder.
- Opret eventuelt Figma-dokument med `wireframes.svg` og `DESIGN.md` som grundlag.
  Figma er dit ønske, men nævnes ikke som et minimumskrav i opgavebeskrivelsen.
- Aktivér GitHub Pages og test det offentlige link.
- Fortsæt med at committe egne ændringer løbende. Denne sessions commits er
  ikke dokumentation for et semesterlangt forløb.
- Forbered showcase: vis video og website, forklar designvalg, teknik, proces,
  Git-historik og refleksion over din læring.

Den endelige side skal kontrolleres igen, når dit eget indhold er sat ind.
