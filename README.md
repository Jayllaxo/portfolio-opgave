# Johans portfolio

En simpel hjemmeside i HTML, CSS og JavaScript. Åbn projektmappen i PhpStorm.
Du kan åbne `index.html` i browseren fra editoren eller starte siden med
`python3 -m http.server 8000` fra projektmappen. Ingen installation er nødvendig.

- `index.html`: forsiden med tre udvalgte projekter.
- `projekter.html`: alle projekter. Kopiér et helt `<article>` for at tilføje flere.
- `style.css`: sidernes design. Farver og skrifttyper står øverst under `:root`.
- `script.js`: kun mobilmenuen.
- `assets/`: almindelige PNG-billeder. Du kan udskifte dem med dine egne billeder
  og rette filnavn og `alt`-tekst i HTML. Tekst og farver inde i billederne ændres
  ved at redigere eller udskifte selve billedet.

Showreel og portræt er stadig pladsholdere. Kommentaren ved showreel-billedet i
`index.html` viser, hvor din egen video skal indsættes, når den er klar.
